TAYLOR MORRISON (current, US home builder). I built an internal document-intelligence RAG platform (closed-loop, not a public chatbot) so project managers, estimators, and sales/design agents ask natural-language questions over dense construction paperwork - RFIs, submittals, change orders, daily reports, invoices, specs, floor plans - and get an exact answer with a citation. Pilot: ~120,000 docs across 3 divisions, ~6,000-8,000 new/month; cut lookup from ~6 minutes to under 20 seconds.
Ingestion (automated, event-driven): upload on the React dashboard > FastAPI stores the raw file in S3 + metadata in PostgreSQL (returns <1s) > S3 event > Celery worker (Redis broker) extracts text/layout (PyMuPDF for digital PDFs, AWS Textract for scans/handwriting), classifies into 8 types with Gemini 2.5 Flash, extracts fields as strict JSON, splits into ~800-1,000-token chunks with ~100 overlap on layout boundaries, embeds with Vertex AI text-embedding-004 (768-dim), and upserts to pgvector (PostgreSQL) with an HNSW index + metadata (doc id, type, section, user permissions, version hash). Batched embeds with exponential-backoff retries for rate limits; on update, delete old vectors by metadata filter then insert.
Retrieval/generation: embed the query > cosine search over HNSW (tuned m/ef_construction) > top 3-4 chunks > cross-encoder rerank > metadata filter on the user's permissions (RBAC enforced in retrieval) > structured prompt ("answer only from context, cite the source, say not-found if absent") > Gemini 2.5 Pro for reasoning/dense tables, Gemini 2.5 Flash for fast lookups. Token-count and truncate before sending. Retrieval p95 <400ms.
Reliability/cost: Redis semantic cache (serve when query similarity >=0.92, <50ms, 24h TTL, invalidate on source change) cut LLM cost ~30%. Anti-hallucination = RAG grounding + strict prompt + rerank + Pydantic JSON-schema guardrails with a self-correction loop. Offline Ragas eval (faithfulness, answer-relevance, context-precision) on a ~500-doc golden set; ~94% classification and ~90% field-extraction accuracy. LangGraph agents with a 15-20 step recursion limit + human-in-the-loop before risky actions; LangSmith traces LLM runs, CloudWatch/X-Ray for infra. LLM ~$0.005/doc, <$150/month at pilot.
